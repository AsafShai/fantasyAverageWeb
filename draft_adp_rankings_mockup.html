ADP is arguably the right default here. A draft board predicts where players actually go — that is what ADP measures. Rankings answer a different question (where they should go), so offering both is useful, but the default should stay ADP.
What changed vs today
View toggle is the only new chrome. Everything else is the existing page — same header, same Sites card, same sticky Player column, same per-cell #rank subscript.
One checkbox per site, exactly as today — checked shows the column and counts toward Blend. To blend Yahoo + Fantrax only, uncheck ESPN. No popover, no second control.
The same selection appears on all three draft pages and is one piece of state — change it anywhere and the other pages follow. Try it: uncheck a site above, then scroll down and watch the Pre-Draft and Draft Board control and ordering change with it.
Persisted to localStorage via the existing usePersistedState hook, keyed per view — so an ADP-view choice never clobbers a Rankings-view choice.
Sites with no data for the active view are not rendered at all. Switch to Rankings: Fantrax disappears. Switch to ADP: Sleeper disappears.
Single-site rows show Blend as is — no minimum-site threshold. Rui Hachimura is listed only by Fantrax, so his Blend is that value; the empty Spread is what signals it was not averaged.
CSV header is unchanged — blend, blend_rank, <site>_adp, <site>_rank keep their names, so the Chrome extension's parser keeps working untouched. Rankings adds new fields alongside; it renames nothing.
