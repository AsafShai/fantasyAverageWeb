Slot Games Estimator — Implementation Plan

1. File

2. Constants

SlotCap (max games)

UTIL248  (82 × 3 + 2)

UTIL cap already encodes 3 stacked slots — no special handling needed in the formula.

3. Inputs

Accepts the DataFrame produced by get_team_slot_pace_df() directly.

League-wide scalars read from the first row (same for all teams):

  • \( p \) — nba_avg_pace: average games played per NBA team so far
  • \( d \) — nba_game_days_remaining: game days left in regular season

Per team × slot:

  • \( g \) — games used in this slot so far this season

4. Weights

The weight signal is how far through the NBA season we are by games played:

\[ w_2 = \frac{p}{82}, \qquad w_1 = 1 - w_2 \]
Season phase\(p\)\(w_1\) (method 1)\(w_2\) (method 2)
Earlysmall≈ 1≈ 0
Late→ 82≈ 0≈ 1

5. Projection Formulas

Method 1 — Season-pace extrapolation

Extrapolate current slot usage to a full 82-game season at current NBA pace:

\[ M_1 = \min\!\left( g \cdot \frac{82}{p},\ \text{cap} \right) \]

Method 2 — Days-remaining projection

Project remaining games from actual days left, then add what's already played:

\[ M_2 = \min\!\left( g + \frac{g}{p} \cdot d,\ \text{cap} \right) \]

Blended projection per slot

\[ \hat{g}_{\text{slot}} = w_1 \cdot M_1 + w_2 \cdot M_2 \]

Total projected games per team

\[ \hat{G}_{\text{total}} = \sum_{\text{slot} \in \{PG, SG, SF, PF, C, G, F, UTIL\}} \hat{g}_{\text{slot}} \]

6. Edge Cases

  • \( p = 0 \): guard with early return — return zeros for all slots.
  • \( g = 0 \) for a slot: projection is 0 (team never used that slot). No division issue.
  • Cap already reached: both methods clamp to cap → blended result = cap.
