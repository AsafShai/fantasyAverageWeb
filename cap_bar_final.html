How the height came down. v1 put the chips on their own line always — 55px per slot, 440px total. Here the numbers move into fixed 34px columns on the same line as the bar (≈26px per slot), and the column headers USED · EST · MAX · CAP carry the labels once instead of eight times. Below 640px it falls back to the chip layout, where labels return per-chip because there is no header row to align to.

Where it still costs you. The mobile fallback is ~2 lines per slot, so 375px is taller than desktop. That is the trade for not scrolling sideways — today's table is shorter on mobile only because you can't see two-thirds of it.
