Same trap as Tools. "Analytical data" has no failing case — Player Rankings is analysis, Estimator is analysis, Draft Report is analysis. A predicate that accepts everything produces a drawer that accepts everything. That is precisely how Tools ended up holding Trends and Draft Report.
