5. Migration notes

DashboardRemove nav entry; keep / route; make logo/app-name a Link to="/".
Analytics pageNav item unchanged — still a single link to /analytics. Add Shots' table as a 3rd section on that page, all columns kept, section heading stays "League Shooting Statistics" (existing text, unchanged). Sections switched via sticky in-page sub-tabs (Heatmap / Rankings Over Time / Shooting Stats), not plain scroll-stack — reuses the .tabbtn pattern already on this page's design. Remove/redirect the standalone /shots route. Rankings Over Time stays here only, not duplicated elsewhere.
Rankings / Player RankingsBoth stay flat top-level links, no dropdown. "Rankings" nav label renamed to "League Rankings" (existing /rankings route, label only). "Player Rankings" (flag, existing /player-rankings route) sits next to it as its own top-level item. Routes unchanged.
Tools groupNew hover-dropdown nav component + mobile accordion variant. Order: Projections, Estimator, Trade (+ Feature Store, dev-build only). Routes unchanged for all. Trigger gets its own icon (🛠️) and stays icon-only between md/xl like every other item, caret always visible. Built as a real <button> with aria-haspopup/aria-expanded; Enter/Space toggles, Escape closes and refocuses the trigger, Arrow-Down opens and focuses the first item, Tab-out closes it.
Player Rankings / ProjectionsStay flag-gated. Player Rankings renders inside the Rankings dropdown; Projections renders inside the Tools dropdown, whenever each flag is on.
Feature StoreStays flag-gated inside Tools dropdown; flag is false in prod builds so it never appears for real users.
Whole reorgGated behind one new flag, VITE_FF_NAV_REORG. Off → current flat nav renders unchanged (existing navItems array in Layout.tsx untouched). On → grouped/reordered nav renders instead, as a separate render branch, same component, no route changes either way. Vite bakes VITE_* at build time (same as the other flags here) — flipping it for season start means setting the env var on Render and redeploying, not a live runtime toggle.
Checked: is Shots redundant with another page? Partially — Rankings.tsx already shows FG% and FT% per team (roto columns, sortable, ranked), duplicating two of Shots' seven columns. But per your call, keep all of them: FG%/FT% in Rankings show your rank in that category, while Shots shows the raw makes/attempts — you need that detail to judge how close you are to passing the team above you (small-sample % swings look different once you see the volume behind them). No trimming.
